## Fixed

1. **Insights DISTRACTION TREND chart ran backwards.**
   `OpportunityCostEngine.lastSevenDayKeys()` returned today→6-days-ago, so
   the chart read newest→oldest while the home-screen TrendWidget and the
   FOCUS/DETOX charts (Mon..Sun) read oldest→newest. Keys are now generated
   oldest-first (`6 downTo 0`); the weekly sums in `snapshot()` are
   order-independent, so nothing else moved.

2. **Leaderboard DP sync never resumed after reinstall / on a second
   device.** The periodic sync gate is the local pref
   `mld_leaderboard_opted_in`, which only the opt-in dialog ever set. A user
   who had opted in on the server (fresh install, second device) saw the
   board but their DP silently never synced again. The Leaderboard tab's
   `_load()` now mirrors the server's `optedIn=true` into the local pref
   (one-way: local stays false when the server says opted-out).

## Added — the one genuinely missing Insights surface

3. **TOP DISTRACTING APPS TODAY card (Insights).** Every screen-time app
   answers "where did the time actually go"; Insights only had aggregate
   minutes. New display-only surface, no enforcement authority:
   - `BrainRotEngine.topDistractingAppsJson()` — reuses UsageTracker's
     already-sorted top-25 foreground list, filtered by the SAME
     `PolicyEngine.isDistracting` classification the brain-rot stage uses,
     computed off the main thread, exception-safe.
   - `NativeBridge.getTopDistractingApps` → Dart `getTopDistractingApps()`.
   - Insights card: rank, app label, h/m — hidden entirely on a quiet day
     (empty list), consistent with the no-nag honesty policy.
