# r9.5 (v2.5.5 / versionCode 20) — engine 2 schedules/limits, task-removal restarts, allowlists

Items 3-5 of the audit's priority list. Built on r9.4.

## Engine 2 now enforces schedules and per-app daily limits
Before, engine 2 (the usage-stats poller that takes over when the accessibility
service dies) only enforced sessions and monk mode; blocking schedules and app
limits silently stopped whenever the accessibility process was killed.
- `enforceAlwaysOn` in `ForegroundAppMonitorService` applies the same two rules
  as the accessibility path (schedule block, daily-limit wall) with the same
  hard boundaries (emergency, system essentials and this app are never walled).
- Engine 2 no longer stands down while such rules exist
  (`AlwaysOnRules.exist`); it also no longer stands down during a monk
  lockdown.
- The guard job starts engine 2 for these rules when accessibility is turned
  off / the process is dead (screen-on only for the "stale heartbeat" case, so
  an idle phone does not keep a service running), and the accessibility
  service's unbind / destroy hand-off does the same. No alarm notification is
  posted for the always-on-only case — engine 2's own notification is the signal.
- Not covered by engine 2 (by design): the reels / shorts detector, which needs
  view-ids from the accessibility tree.

## Task removal no longer ends enforcement
`onTaskRemoved` for lock-my-phone and engine 2 (monk and the enforcement
service already had it) re-arms a restart ~1.5 s later via an exact alarm
(`PendingIntent.getForegroundService`, exact when permitted).
`ServiceRevival.scheduleServiceRestart`.

## Hard blocks flush the app
A hard block now also calls `killBackgroundProcesses(pkg)` ~0.7 s after the app
is sent HOME (Social Sentry mechanism #26), so it cannot resume behind the wall.

## Study allowlists
Study setup offers 12 grouped allowlists (Phone & Contacts, Camera, Gallery,
Calculator, Notes, AI assistants, Docs & PDF, Scanner, Online classes, Files,
Translate, Chrome). One toggle covers the equivalent app on common OEM package
names; packages that are not installed are simply ignored. (The previous
version listed 4 fixed packages, e.g. only Samsung's calculator.)
