# R11.1 Changes — v2.5.9 Opportunity-Cost Nudges (user-requested)

Builds on R10 (audit fixes) and R11 (leaderboard / trend widget / detection
rules). One focused addition, fully local — no worker, admin or DB changes.

## The idea (in the user's words)

"Take bolbe eivabe shomoy noshto korle eto din pisaya jabe ... ei shomoy
kaje lagale eita hoto." — when the user is caught wasting time, show them,
with THEIR OWN numbers, what the habit costs per year and what the same
hours could have produced.

## `growth/OpportunityCostEngine.kt` (new)

- Data: the same Room `daily_stats` columns the trend widget already keeps —
  `distractingMinutes` (v2.5.8 high-water mark) and `shortsWarnings` (every
  intercepted reel). Display-only; never an enforcement input.
- Projections (deterministic constants, honest arithmetic):
  - yearly days lost = weeklyHours × 52 / 24
  - books/year = weeklyHours × 52 / 6h per book
  - ৳/year = weeklyHours × 52 × ৳100/hour (illustrative informal-sector rate,
    labeled as such — the copy says "hoto" (would have been), never promises)
- A quiet week (< 30 distraction minutes) produces NO nudge — zero-nudges
  are worse than silence.

## Surfaces

1. **Reels overlay (soft + hard cards)** — one rotating Banglish line with
   the user's real numbers (e.g. "Ei hizbe cholle bosore puro 6 din shudhu
   scroll e chole jabe. Ei shomoy ta kaje lagle 52 ta boi shesh hoto."),
   loaded off-thread; the overlay never waits on it.
2. **Daily insight notification** — the line is appended when today's
   distracting time ≥ 30 minutes (quiet days stay quiet).
3. **Insights screen** — new "WHAT THIS TIME WAS WORTH" card with the
   projection math spelled out, plus a "DISTRACTION TREND" bar chart (the
   in-app twin of the home-screen trend widget) and a weekly
   reels-skipped total.

## Bridge

- `NativeBridge.getOpportunityCost` → `{enabled, weeklyMinutes,
  yearlyHours, yearlyDaysLost, booksPerYear, takaPerYear, reelsBlockedWeek,
  focusHoursWeek, line, hourlyRateBdt}`
- `NativeBridge.getDistractionTrend` → 7 zero-filled days (oldest first):
  `{date, distractingMinutes, reelsBlocked, focusMinutes}`
